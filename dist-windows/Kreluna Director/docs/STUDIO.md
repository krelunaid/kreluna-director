# Manuale studio

Tu parli solo con **Kreluna Director**.

1. Entra nella dashboard.
2. Scrivi l’obiettivo (fattura, controllo, F24 da preparare).
3. Il Director sceglie il PC (Fatture, Pagamenti, F24, …).
4. Guarda lo screenshot.
5. Approva o rifiuta.

Non registri il monitor. Non insegni i click. I programmi si collegano dopo, un PC alla volta.

Login demo: `andrea@studio.demo` / `demo`

Installazione sul computer: `docs/INSTALL.md` (zip Mac e zip Windows, senza installare Python).
