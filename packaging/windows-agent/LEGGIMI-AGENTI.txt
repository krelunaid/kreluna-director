KRELUNA AGENTI — UN PROGRAMMA PER OGNI PC
=========================================

Il Director (cervello) sta su UN computer o sul link web.
Ogni altro PC dello studio ha UN Agent, diverso.

1. Apri director.url con il Blocco note.
   Scrivi l'indirizzo del Director, una riga sola.
   Esempio: http://192.168.1.10:8080

2. Sul PC giusto fai DOPPIO CLIC su UN file solo:
   - Installa PC-FATTURE.bat      → Webdesk / sito AdE
   - Installa PC-F24.bat          → IPSOA, poi Telematico
   - Installa PC-CONTABILITA.bat  → scarico AdE, carico IPSOA
   - Installa PC-CAMERALI.bat     → sito CGN, Desktop ComUnica
   - Installa PC-CONTRATTI.bat    → sito AdE di Samuele
   - Installa PC-DURC.bat         → sito INPS
   - Installa PC-VISURE.bat       → sito CGN

3. Se Windows avvisa: Altre informazioni → Esegui comunque.

Sul desktop compare "Kreluna Agent …". Lascialo acceso.
In dashboard Kreluna quel PC diventa online.

PC-FATTURE chiede anche il percorso del programma .exe o l'indirizzo HTTPS
del portale. Puoi lasciarlo vuoto per la prova locale. Non inserire password
nell'indirizzo: le credenziali restano nella Cassaforte e il login SPID/CNS è manuale.

Non installare il Director su questi PC.
Non installare due Agent sullo stesso PC.
In demo l'Agent NON usa SPID, smart card, Telematico o INPS veri:
mostra solo la scheda sul PC. L'invio reale resta spento.
